# Historical 0.2.x reports

The files in this directory document previous AMDE 0.2.x builds and experiments. They are preserved for provenance and are not evidence for AMDE 1.0.0. Current release details are in the top-level `reports/` documents and the project `README.md`. The active release is AMDE 2.0.0; this folder remains historical provenance.

The `prompts/` folder preserves old 0.2.x merge/rebuild prompts. The `pre_seed_fix/` result JSON files are historical experiments and must not be compared as AMDE 1.0.0 results.
