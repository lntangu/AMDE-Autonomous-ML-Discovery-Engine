## Reporting a Vulnerability

We take the security and integrity of the AMDE research platform seriously.

If you believe you have discovered a vulnerability, security flaw, or credential exposure in this repository:

1. **Do not** disclose the issue publicly via GitHub Issues or Discussions.
2. Please report the issue privately by sending an email to:  
   **`lnta17092012@gmail.com`**
3. Please include:
   - A clear description of the vulnerability.
   - Exact steps or minimal script to reproduce the issue.
   - Any potential impact on process containment or host security.
4. You will receive an acknowledgment within 48 hours, followed by updates as the issue is verified and remediated.
