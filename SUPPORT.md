# Support & Community Guidance

Welcome to the AMDE (Autonomous Machine Learning Discovery Engine) research project.

## How to Get Help

* **Documentation**: Detailed guides are located in the [`docs/`](docs/) directory:
  * [Architecture Overview](docs/ARCHITECTURE.md)
  * [Installation Guide](docs/INSTALLATION.md)
  * [Quickstart](docs/QUICKSTART.md)
  * [Troubleshooting](docs/TROUBLESHOOTING.md)
* **Bug Reports & Issues**: If you encounter an unexpected error, crash, or reproduction discrepancy, please open an issue on the [GitHub Issue Tracker](https://github.com/lntangu/AMDE-Autonomous-ML-Discovery-Engine/issues). Please include your Python version, OS environment, hardware specs, and relevant log outputs.
* **Research Inquiries**: For questions regarding empirical findings, benchmark protocols, or algorithmic collaboration, please use GitHub Discussions or contact project maintainers.
